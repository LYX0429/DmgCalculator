# 伤害计算器设计文档

**日期：** 2026-05-18  
**项目：** 类宝可梦伤害计算器（纯 HTML/CSS/JS）

---

## 背景

制作一个本地运行的伤害计算器网页，不依赖任何后端或服务器。精灵和技能数据以 JS 文件形式存储，直接在浏览器中加载。

## 数据结构

### creatures.js

```js
const CREATURES = [
  {
    id: "example",
    name: "示例精灵",
    types: ["火", "飞"],                         // 1~2 个属性
    baseStats: {
      hp: 78, atk: 84, spatk: 109,
      def: 78, spdef: 85, spd: 100
    },
    ivs: { spatk: 60, spd: 54, hp: 48 },        // 最多 3 个属性有个体值，其余为 0
    nature: { name: "内敛", boost: "spatk", reduce: "atk" },
    commonMoves: ["flamethrower", "air-slash"]
  }
]
```

### moves.js

```js
const MOVES = [
  {
    id: "flamethrower",
    name: "火焰放射",
    power: 90,
    category: "special",   // "physical" | "special"
    type: "火"
  }
]
```

### 性格（内置在 calculator.js）

每个性格使一个属性 ×1.2，另一个属性 ×0.9，无加成性格所有属性 ×1.0。
适用属性：atk、def、spatk、spdef、spd、hp（自定义系统，HP 也可受性格影响）。

---

## 属性值计算公式

```
HP   = floor([1.7 × base + IV × 0.85 + 70] × (1 + natureBoost)) + 100
其他 = floor([1.1 × base + IV × 0.55 + 10] × (1 + natureBoost)) + 50
```

- IV 可选值：0 / 42 / 48 / 54 / 60（每只精灵最多 3 个属性有 IV）
- natureBoost：该属性被性格加成则 +0.2，减成则 −0.1，否则 0

---

## 伤害公式

```
伤害 = floor(
  我方攻 / 敌方防
  × 0.9
  × (技能威力 + 额外威力)
  × (1 + 攻击Buff)
  / (1 + 防守Buff)
  × 属性克制
  × 本系加成
)
```

- **我方攻**：物理技能用 atk，魔法技能用 spatk
- **敌方防**：物理技能用 def，魔法技能用 spdef
- **属性克制**：技能属性克制敌方 1 个属性 ×2，克制 2 个属性 ×3
- **本系加成**：技能属性 ∈ 我方精灵属性列表 → ×1.25，否则 ×1

## 结果展示（横条）

针对敌方的 7 种假设组合分别计算，每条横条宽度代表伤害占敌方 HP 的比例：

| # | 敌方 HP 条件 | 敌方防御条件 |
|---|-------------|-------------|
| ① | 满个体 + 性格加成 | 满个体 + 性格加成 |
| ② | 满个体 + 性格加成 | 满个体，无性格加成 |
| ③ | 满个体，无性格加成 | 满个体 + 性格加成 |
| ④ | 满个体，无性格加成 | 满个体，无性格加成 |
| ⑤ | 满个体，无性格加成 | 无个体，无性格加成 |
| ⑥ | 无个体，无性格加成 | 满个体，无性格加成 |
| ⑦ | 无个体，无性格加成 | 无个体，无性格加成 |

每行显示：标签 + 横条（宽度 = 伤害/HP%）+ 伤害数值 + 百分比

额外标注：
- **绝对最小值**：HP IV60×1.2，防 IV60×1.2
- **绝对最大值**：HP IV0×1.0，防 IV0×0.9（防御性格 −0.1）
